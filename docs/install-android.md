# تثبيت تطبيق الميدان على جوالات السفراء

في طريقتين. الأولى بتكفي وما بتحتاج شي، والتانية بتعطي ملف APK.

## الطريقة 1: من المتصفح (PWA) — دقيقة وحدة

1. افتح عنوان الموقع بـ Chrome على الجوال وسجّل دخول.
2. افتح «تطبيق الميدان» من القائمة (أو العنوان `/m`).
3. من قائمة Chrome (⋮) اختار **«تثبيت التطبيق»** أو «إضافة إلى الشاشة الرئيسية».
4. بتطلع أيقونة «الميدان» على الشاشة، والتطبيق بيفتح بدون شريط المتصفح وبيشتغل بدون نت.

لازم الموقع يكون على **https**. بدون https المتصفح ما بيسمح بالتثبيت ولا بالأوفلاين ولا بالـ GPS.

أول مرة افتح التطبيق والنت شغّال عشان يحفظ الشاشات والقوائم على الجوال.

## الطريقة 2: ملف APK (Trusted Web Activity)

بتنعمل مرة وحدة على كمبيوتر فيه Node 22 وJava 17، بعد ما يتحدد عنوان الموقع النهائي.

```bash
npm i -g @bubblewrap/cli
# 1) بدّل REPLACE-WITH-SITE-HOST بملف twa-manifest.json بعنوان الموقع (بدون https://)
bubblewrap update --manifest ./twa-manifest.json   # أول مرة بينزّل أدوات أندرويد وبينشئ مفتاح التوقيع
bubblewrap build                                   # بيطلع app-release-signed.apk
bubblewrap fingerprint                             # بيعرض بصمة SHA-256
```

بعدها على السيرفر، بملف `.env`:

```
TWA_PACKAGE_NAME=ps.jawwal.ambassadors.visits
TWA_SHA256_FINGERPRINTS=AA:BB:...   # البصمة من الأمر الأخير
```

وأعد تشغيل الموقع (`docker compose up -d`). تأكد إن `https://الموقع/.well-known/assetlinks.json` بيعرض البصمة. بدون هالخطوة التطبيق بيفتح مع شريط المتصفح.

ابعت ملف الـ APK للسفراء (واتساب أو كابل)، وعلى الجوال: افتح الملف ← اسمح «تثبيت من مصادر غير معروفة» ← تثبيت.

**مهم:** احفظ ملف `android.keystore` وكلمة سره بمكان آمن. بدونه ما بتقدر تطلع نسخة جديدة من نفس التطبيق.

## التحديثات

التطبيق هو الموقع نفسه، فأي تحديث على السيرفر بيوصل لحاله بدون إعادة تثبيت، بالطريقتين.

## إذا ضاع جوال

من الموقع: المستخدمون ← «طرد من كل الأجهزة» لصاحب الجوال. العناصر اللي بانتظار الإرسال على الجوال الضايع ما بتنبعت بعدها.
