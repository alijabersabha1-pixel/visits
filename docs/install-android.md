# تطبيق الميدان على أندرويد

في طريقتين، والتنتين بيفتحوا نفس التطبيق وبيشتغلوا بدون نت.

## الطريقة 1: من المتصفح (بدون أي ملف) — الأسهل

1. افتح رابط النظام بكروم على الجوال وادخل بحسابك.
2. من قائمة كروم (⋮) اختار **«تثبيت التطبيق»** أو **«إضافة للشاشة الرئيسية»**.
3. بتطلع أيقونة «الميدان» على الشاشة، وبتفتح على «زيارة جديدة» بدون شريط المتصفح.

أي تحديث بالموقع بيوصل للتطبيق لحاله.

## الطريقة 2: ملف APK (بيعمله قسم IT مرة وحدة)

ملف الـ APK غلاف (Trusted Web Activity) بيفتح نفس الموقع، فالتحديثات بتوصل بدون إعادة تثبيت. لازم يكون النظام على رابط HTTPS نهائي قبل ما ينعمل.

المطلوب على جهاز الكمبيوتر: Node 22 وJava 17 (Bubblewrap بينزّل Android SDK لحاله).

```bash
npm i -g @bubblewrap/cli
cd android
# 1) غيّر visits.example.ps بـ android/twa-manifest.json للرابط الحقيقي
# 2) بناء التطبيق (أول مرة بيعمل مفتاح توقيع ambassadors.keystore — احفظه بمكان آمن)
bubblewrap init --manifest https://<الرابط>/manifest.webmanifest   # أو استعمل twa-manifest.json الجاهز
bubblewrap build
# 3) بصمة المفتاح
keytool -list -v -keystore ambassadors.keystore -alias ambassadors | grep SHA256
```

4. حط البصمة مكان `REPLACE_WITH_KEYSTORE_SHA256_FINGERPRINT` بـ `public/.well-known/assetlinks.json` وانشر الموقع. بدون هالخطوة التطبيق بيفتح بشريط متصفح فوق.
5. ابعت ملف `app-release-signed.apk` للسفراء. على الجوال: افتح الملف ← اسمح بالتثبيت من هالمصدر ← تثبيت.

**مهم:** مفتاح التوقيع `ambassadors.keystore` لازم ينحفظ. أي تحديث للـ APK لازم يتوقع بنفس المفتاح.

## صلاحيات الجوال

أول مرة بيطلب التطبيق إذن **الموقع** (للـ GPS) و**الكاميرا** (للصور). لازم توافق عليهم. إذا رفضتهم بالغلط: إعدادات ← التطبيقات ← الميدان (أو كروم) ← الأذونات.
