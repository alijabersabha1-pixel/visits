# نسخة العرض للإدارة

نسخة كاملة من النظام ببيانات **وهمية بالكامل**: 197 خط (أكوادها `T-…`)، 420 زيارة على 12 شهر، 18 حالة VPN، 40 بطاقة، وإعادات زيارة وطلب تعديل. ولا حرف من بيانات مشتركين حقيقية، و`scripts/seed-demo.ts` بيرفض يشتغل على قاعدة فيها بيانات.

## وين نستضيفها؟ (قرارك)

| الخيار | الكلفة | يناسب؟ |
| --- | --- | --- |
| **سيرفر Oracle Cloud المجاني (Ampere A1)** | مجاني | **نعم**. من آب 2026 صار 2 معالج و12 GB ذاكرة، وهاد بيكفي النظام كله (قاعدة البيانات والموقع والـ PDF). بيشغّل `docker compose` متل سيرفر الشركة بالضبط. ممكن ما يكون في سعة فاضية بالمنطقة أول ما تسجّل، وOracle ممكن تسترجع السيرفر إذا ضل فاضي فترة طويلة |
| Render (الخطة المجانية) | مجاني | لا. 512 MB ذاكرة، وبينام بعد 15 دقيقة (أول فتحة بتاخد دقيقة)، وقاعدة البيانات المجانية بتنمسح بعد 30 يوم، والصور ما بتنحفظ |
| سيرفر صغير مدفوع (VPS) | تقريباً 4–6 دولار بالشهر | نعم، وأريح من Oracle. بس هاد خدمة مدفوعة، فبدها موافقتك |
| جهاز داخل الشركة | مجاني | الأفضل إذا IT بيوافقوا على جهاز تجربة |

## التشغيل (أي سيرفر Linux فيه Docker)

```bash
git clone <المستودع> visits && cd visits
cp .env.example .env          # عبّي القيم حسب docs/deploy.md
docker compose up -d --build
docker compose run --rm -e DEMO_PASSWORD='<كلمة سر العرض>' tools npm run seed:demo
```

الحسابات كلها بنفس كلمة سر العرض: `ali` و`sami` و`yousef` (سفراء)، و`boss` (مسؤول للقراءة).

HTTPS: بدونه تطبيق الجوال ما بيتثبت ولا بياخد GPS. أسهل طريقة على سيرفر العرض: Caddy قدّام الموقع، بيجيب شهادة لحاله:

```
visits-demo.example.com {
  reverse_proxy 127.0.0.1:3000
}
```

لإعادة العرض من الأول: `docker compose down -v` (بيمسح كل شي) وبعدين الأوامر فوق.

## سيناريو العرض (15 دقيقة تقريباً)

| # | وين | شو بتعرض | شو بتحكي |
| --- | --- | --- | --- |
| 1 | دخول `boss` ← الرئيسية | الأرقام فوق، الرسم الشهري، التنبيهات | «هيك المسؤول بيشوف شغل الفريق كل يوم، بدون ما يطلب إكسل» |
| 2 | الرسم الشهري | مرّر الماوس على شهر، وبعدين «عرض كجدول» | نسبة التجاوز كل شهر، وكل رقم بيتطابق مع قائمة الزيارات |
| 3 | الخريطة | الدبابيس بالألوان، كبّر على منطقة، انقر دبوس | «وين التجاوزات متجمعة»، واللوحة الجانبية فيها تاريخ الخط كله |
| 4 | البحث بالـ Line Code | اكتب `t 1021 001` (بأي شكل) | بطاقة الخط وكل زياراته بثانية، وخطوط نفس الحساب |
| 5 | الزيارات | فلتر «يوجد تجاوز» + الجنوب، حدد زيارتين، PDF مفصّل | تقرير جاهز للطباعة بلوجو جوال |
| 6 | سجل التعديلات | فلتر حسب سفير | كل تعديل بالاسم والوقت والقيمة القديمة والجديدة، وما بينمسح |
| 7 | البطاقات ← التقرير الشهري | PDF وExcel | تقرير الصرف آخر الشهر جاهز |
| 8 | جوال: دخول `ali` ← تطبيق الميدان | وضع الطيران ← زيارة جديدة ← حفظ ← رجّع النت | «السفير بيسجل من الميدان حتى بدون نت، وبتوصل لحالها مرة وحدة» |
| 9 | الموقع (من الكمبيوتر) | افتح الزيارة اللي انبعتت | الموقع والوقت من لحظة التعبئة بالميدان |
| 10 | `boss` يحاول يعدّل | ما في أزرار تعديل | المسؤول بيشوف بس، والصلاحيات على السيرفر مش بالشاشة بس |

**قبل العرض بيوم:** افتح كل خطوة مرة، وثبّت التطبيق على الجوال اللي رح تعرض منه، وتأكد إن صور الخريطة بتحمّل على نت مكان العرض.

## أسئلة متوقعة

| السؤال | الجواب |
| --- | --- |
| وين البيانات الحقيقية؟ | على سيرفرات الشركة بس. نسخة العرض وهمية |
| شو بيصير إذا ضاع جوال سفير؟ | «طرد من كل الأجهزة» من صفحة المستخدمين، فوراً |
| كلمات سر المايكروتيك؟ | مشفّرة، وكل مرة حدا بيشوفها بتنسجل، والمسؤول ما بيقدر يشوفها |
| النسخ الاحتياطي؟ | يومي ومشفّر، والاسترجاع انجرّب (docs/deploy.md) |
| بدنا آيفون؟ | خارج النسخة الأولى. التطبيق ويب، فبيفتح على آيفون من Safari، بس بدون اختبار كامل |
