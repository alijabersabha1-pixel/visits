## قبل التشغيل على سيرفر الشركة (بيعملها قسم IT)

1. **فحص OWASP ZAP** (ما انعمل هون لأن بيئة البناء بدون Docker):
   ```bash
   docker run --rm -t ghcr.io/zaproxy/zaproxy:stable zap-baseline.py -t https://<الرابط> -r zap.html
   ```
   أي نتيجة عالية أو متوسطة لازم تتصلّح قبل التشغيل.
2. **تواقيع المكتبات:** `npm audit signatures` (بتحتاج نت).
3. **الفحص الحي على السيرفر نفسه** مع حساب تجربة، لازم يطلع 0:
   ```bash
   CHECK_USER=<حساب> CHECK_PASS=<كلمة سر> node scripts/security-check.mjs https://<الرابط>
   ```
4. `COOKIE_SECURE=true` و`APP_ORIGIN=https://…` بملف `.env`.
5. الموقع يتصل بقاعدة البيانات بمستخدم **مش** مالك الجداول، عشان ما يقدر يطفي محفّز السجل (`docs/deploy.md`).
