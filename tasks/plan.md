# خطة التنفيذ: نظام زيارات فريق السفراء — جوال

المواصفات المعتمدة: https://claude.ai/artifact/Bm17wivmGKuNL1KPbjBsR5 (اعتمدها علي جبر بتاريخ 2026-11-13).
قائمة المهام التفصيلية: `tasks/todo.md`.

## الملخص

نبني موقعاً وتطبيق أندرويد (PWA + APK) بكود واحد، يحلّان محل ملف الإكسل الحالي (949 زيارة). البناء على 6 مراحل. كل مهمة شريحة كاملة تشمل قاعدة البيانات والسيرفر والواجهة، وكل مرحلة تنتهي بنقطة مراجعة مع علي. بعد المرحلة 3 تصير عندنا نسخة شغالة تغني عن الإكسل.

## قرارات معمارية

| القرار | السبب |
| --- | --- |
| Next.js + TypeScript، كود واحد للموقع والجوال | 3 سفراء فقط وكلهم أندرويد. PWA تعطي أوفلاين وGPS بدون متجر، وصيانة كود واحد أسهل |
| PostgreSQL + Prisma داخل Docker | ينتقل لسيرفرات الشركة كما هو، وقاعدة بيانات مفتوحة المصدر بدون ترخيص |
| جلسات بكوكي httpOnly بدل JWT | تسمح بإلغاء جلسة جوال ضايع فوراً |
| الصلاحيات تُفحص بطبقة واحدة `lib/authz` على السيرفر | قاعدة "التقرير لصاحبه والحالة للجميع" تتطبق في مكان واحد وتُختبر مرة واحدة |
| السجل جدول إلحاق فقط (append-only) يُكتب داخل نفس عملية الحفظ | لا يوجد تعديل بلا سجل، ولا سجل بلا تعديل |
| كل عنصر أوفلاين يحمل UUID ينشئه الجوال (مفتاح عدم تكرار) | الإرسال المكرر بسبب ضعف النت لا ينشئ نسخة ثانية |
| المزامنة عند حدث `online` وعند فتح التطبيق وبالـ Background Sync إذا توفر | Background Sync وحده غير مضمون على كل الأجهزة |
| كلمات سر المايكروتيك مشفرة AES-256-GCM والمفتاح بمتغير بيئة | تسريب قاعدة البيانات وحدها لا يكشف كلمات السر |
| PDF من Chromium على السيرفر | العربي من اليمين لليسار يطلع صحيح، بخلاف مكتبات PDF العادية |
| Leaflet + OpenStreetMap | مجاني بالكامل، بدون مفتاح أو حساب دفع |
| القوائم (التوصية، الإجراء، أسئلة المايكروتيك) جداول قابلة للتعديل، والقيم توقف ولا تنحذف | المسؤول يعدّلها بدون مبرمج، والزيارات القديمة تبقى سليمة |
| الهوية: أخضر جوال `#77BB45` وأزرق جوال `#115D92` (مأخوذة من اللوجو المرسل) | طلب علي |
| دوران: السفير بيعمل كل شي، والمسؤول قراءة بس (تصحيح 2026-11-13) | المسؤول بيراقب من بعيد وما بيتحكم بشغل السفراء |
