# نظام زيارات فريق السفراء — جوال

موقع وتطبيق ميدان لأندرويد (PWA، وممكن APK) بيحلّوا محل ملف الإكسل. المواصفات:
[مستند المواصفات](https://claude.ai/artifact/Bm17wivmGKuNL1KPbjBsR5) · الخطة: `tasks/plan.md` · المهام: `tasks/todo.md`.

**الحالة:** المراحل الست كلها مبنية ومختبرة (28 مهمة). الباقي خطوات بتصير على السيرفر الحقيقي، وهي بآخر هالملف.

**الأدوار:** السفير بيعمل كل شي، والمسؤول بيشوف كل شي للقراءة بس.

## شو فيه

| | |
| --- | --- |
| الزيارات | تسجيل من الموقع أو الميدان، تقرير لصاحبه وحالة للكل، طلبات تعديل بموافقة، سلة محذوفات، إعادة زيارة بتأجيل |
| البحث | بالـ Line Code بأي شكل، بطاقة الخط وتاريخه، وبحث جماعي لغاية 1000 كود |
| البيانات | ملف الشهر من الإدارة (معاينة قبل الحفظ)، خطوط طارئة يدوياً، نقل 949 زيارة قديمة بتقرير مراجعة |
| الميدان | تطبيق بيشتغل بدون نت: زيارة مع GPS وصور وأسئلة مايكروتيك، حالات VPN، شراء بطاقات. الإرسال لحاله ومرة وحدة |
| المايكروتيك | أسئلة قابلة للتعديل، قائمة «بحاجة access»، كلمات سر مشفّرة مع سجل عرض |
| العرض | رئيسية بالأرقام والرسوم والتنبيهات، خريطة بالدبابيس، تصدير PDF وExcel، تقرير البطاقات الشهري |
| الأمان | Argon2id، قفل بعد 5 محاولات، تحديد معدل، صلاحيات على السيرفر، سجل تعديلات ما بينمسح، نسخ احتياطي مشفّر |

## التشغيل على سيرفر

الدليل الكامل لقسم IT: **`docs/deploy.md`**. باختصار:

```bash
cp .env.example .env          # عبّي القيم (docs/deploy.md بيشرح كل وحدة)
docker compose up -d --build  # قاعدة البيانات + الموقع، والـ migrations بتنطبق لحالها
docker compose run --rm tools npm run create-user -- --username ali --name "علي جبر"
docker compose run --rm backup   # نسخة احتياطية (وكل يوم بـ cron)
```

نسخة العرض للإدارة ببيانات وهمية: **`docs/demo-script.md`**. تطبيق الجوال: **`docs/install-android.md`**.

## التطوير

يحتاج Node 22 وPostgreSQL 16.

```bash
npm ci
cp .env.example .env
npm run db:migrate
npm run create-user -- --username ali --name "علي جبر"                      # سفير
npm run create-user -- --username boss --name "المسؤول" --role MANAGER    # مسؤول للقراءة
npm run dev                   # http://localhost:3000
```

بيانات تجربة على قاعدة فاضية: `DEMO_PASSWORD=… npm run seed:demo`.

## الفحوصات

```bash
npm run lint && npm run typecheck
npm test                      # اختبارات الوحدات (قاعدة visits_test منفصلة)
npm run test:coverage         # نفسها مع التغطية (الحد الأدنى 80% بـ lib/)
npm run build
npm run test:e2e              # اختبارات المتصفح (قاعدة visits_e2e_test منفصلة)
npm run security:check -- http://127.0.0.1:3000   # فحص أمان حي على نسخة شغالة
```

إذا ما بتقدر تنزّل متصفح Playwright: `CHROME_PATH=/usr/bin/google-chrome npm run test:e2e`.
لتشغيل اختبارات المتصفح بمستخدم قاعدة بيانات أقل صلاحيات (متل الإنتاج): `E2E_APP_ROLE` و`E2E_APP_DATABASE_URL`.

## الباقي على السيرفر الحقيقي

هالخطوات ما بتنعمل إلا على سيرفر الشركة أو بموافقتك:

1. **نقل الزيارات القديمة النهائي:** المعاينة والتقرير جاهزين، والحفظ بيصير بعد ما توافق على التقرير (`docs/deploy.md` خطوة 3).
2. **فحص OWASP ZAP وتواقيع المكتبات:** بيحتاجوا Docker ونت (`docs/security-report.md`).
3. **تجربة الاسترجاع على سيرفر فاضي:** الأوامر بـ `docs/deploy.md` خطوة 5. انجرّبت هون على قاعدة فاضية ونجحت.
4. **ملف الـ APK:** بيحتاج رابط HTTPS النهائي (`docs/install-android.md`).
5. **استضافة نسخة العرض:** الخيارات بـ `docs/demo-script.md`، والقرار إلك.
6. **تجربة على الجوالات التلاتة:** أسبوع زيارات حقيقية (نقطة المراجعة 4).
